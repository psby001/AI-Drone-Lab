# AI 中文編程與限制

[返回 README](../README.md) · [JSON 格式與全部動作](mission-system.md)

## 使用流程

1. 開啟「AI 編程」，選擇 OpenAI API Key 或本機 ChatGPT 來源。
2. API Key 由管理者依 `server/.env.example` 設定在 `server/.env`；重啟後可更新模型清單並選擇模型。未選擇時沿用 `OPENAI_MODEL`。
3. ChatGPT 為實驗性本機登入功能：從同一電腦的 localhost／127.0.0.1 操作，完成登入授權並選擇模型，不能供區網其他裝置共用。可用性以實際帳號授權為準。
4. 輸入包含起降、高度、距離、角度的中文任務，或按範例填入。
5. 按「產生任務」，查看步驟與 JSON。通過驗證後按「開始模擬」，或「修改任務 JSON」調整再載入。

> 起飛到 5 公尺，向右平移 4 公尺，右轉 90 度，前進 6 公尺，懸停 2 秒，最後降落。

「向右平移」與「右轉」是不同動作；「同時前進並右轉」可轉為 parallel。欠缺必要量值、未說明起降或語意不明時，AI 應先詢問；超限制時應拒絕，不自行縮短需求。

## 模型與回應

API 模型清單由後端使用自己的金鑰取得，快取 60 秒；清單表示可取得該模型，不保證支援本專案所需 Responses API 與 Structured Outputs。不相容時請更換模型，不會自動切換模型或 AI 來源。

AI 回應為 ready（可預覽）、clarification（需補充）或 rejected（拒絕）。ready 任務會依序通過後端與瀏覽器共用驗證，再交給原有 MissionRunner；不會執行 AI 產生的任意程式碼。

## 目前限制

| 項目 | 預設限制 |
| --- | --- |
| 中文輸入 | 最多 1,000 字元；含關卡公開資訊時，共用同一額度，介面會顯示剩餘上限 |
| API Key 逾時 | 後端最多 25 秒；前端等待 30 秒 |
| ChatGPT 逾時 | 後端最多 60 秒；前端等待 65 秒 |
| 每個 IP | 每分鐘 30 次、每小時 120 次 |
| 整體服務 | 每分鐘 60 次、每小時 600 次，最多同時 12 個解析請求 |
| API 輸出額度 | 最多 4,096 output tokens；複雜任務仍可能產生未完成回應 |
| 飛行 | 高度 20m、半徑 50m、水平速度 5m/s、展開 15 條、有效任務 180 秒 |

頻率／併發等後端設定可依 `.env.example` 調整；安全任務限制見 JSON 指南。AI 設定來源為 `src/ai/contracts.ts` 與 `server/config.ts`。解析等待時間與任務飛行時間分別計算。

AI 目前是自然語言轉任務，不具視覺自主搜尋、自動避障或讀取隱藏目標座標的能力。攝影尋寶只傳送允許公開的區域資訊；玩家須指定路線、位置或雲台角度。AI 推論不等於飛行已完成，必須確認預覽再執行。

## 失敗與資料處理

逾時、權限、額度、不相容模型或不合法任務會顯示錯誤，保留學生輸入；仍可使用預設 JSON 與手動飛行。修改輸入、取消或切換來源會丟棄過期回應。

任務描述會傳往所選 AI 服務，請勿輸入個人資料。API Key 僅存後端；ChatGPT 登入資料位於已忽略的本機 `server/.local/`。部署時需依自己的服務設定來源與用量，勿公開私密檔案。
